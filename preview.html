What the courtyard screen has in rotation at any moment. View-only — this page never changes the screen.
SHOWING AS OF
Reads the live playlist.json (same file the screen reads, refreshed on load) and decides what is featured with jade-sched.js — the same module the screen runs, so this page cannot drift from it. All times are venue time (America/New_York), whatever your device is set to. Rotation order on the real screen is not fixed — this shows the pool of signs in rotation, not a frame-by-frame simulation.
Rules: the featured event is today's next start, else today's most recent start (kept until overnight); the corner chip and the countdown card both follow it. Once an event starts, its card switches to SHOWTIME / GAME TIME (no timer) for the rest of that day. Sports events use the broadcast look (red kicker block, gold-bordered timer cells). Series signs (Saturdays, Sundays, Mon/Thu) count down to each real airing but stay one card.
